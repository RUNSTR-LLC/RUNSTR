# Profile Shared Components

Reusable components used across different workout source tabs and profile screens.

## Files

- **EnhancedSocialShareModal.tsx** - Modal for saving workout cards locally with template picker, card preview, camera capture, and fullscreen preview.
- **EnhancedWorkoutCard.tsx** - Workout display card with Post/Public action buttons, source badges, and status indicators.
- **FullScreenCardModal.tsx** - Full screen workout card display for screenshotting, with themed photo overlays (Minimal, Tactical, Tough).
- **FullScreenVerticalCard.tsx** - Native full-screen vertical workout card layout optimized for social media screenshots, with motivational quotes.
- **MonthlyWorkoutGroup.tsx** - Collapsible monthly workout folder that organizes workouts by month with expandable UI and detailed monthly stats.
- **SocialShareModal.tsx** - Modal for sharing workouts to social platforms, currently supporting Nostr with other platforms coming soon.
- **SyncDropdown.tsx** - Dropdown menu providing manual sync control for importing workouts from Apple Health, Garmin, and Google Fit.
- **TimelineEntryCard.tsx** - Renders journal entries and habit check-ins in the unified Health Timeline alongside workout cards.
- **WorkoutCard.tsx** - Universal workout display component with consistent styling, used by all workout source tabs (Nostr, Apple Health, Garmin, Google Fit).
- **WorkoutDetailModal.tsx** - Detailed workout view modal showing splits, weather, activity-specific data, and saved card preview with fullscreen option.
